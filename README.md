# Kabar Htut — Personal Portfolio

Responsive one-page portfolio built with React, TypeScript, and Vite.

## Run locally

```sh
npm install
npm run dev
```

On Windows PowerShell with restricted script execution, use `npm.cmd`.

## Build

```sh
npm run build
npm run preview
```

Build output: `dist/`.

## Features

Home, About, personal information, skills, five professional projects, experience, education, training, volunteer work, and contact. Includes project filters, keyboard-accessible detail dialogs, mobile navigation, section highlighting, scroll reveals, floating portrait, and reduced-motion support.

Edit content in `src/App.tsx` and styles in `src/App.css` and `src/index.css`. Portrait: `public/kabar-htut.png`. Content and portrait are from the supplied document; NRC is omitted. Project interface illustrations are labeled and are not actual project screenshots. Google Fonts have local font fallbacks.

Production build verified. Browser visual and interaction checks were not available. A private Sites identity is saved in `.openai/hosting.json`; publication has not completed.
